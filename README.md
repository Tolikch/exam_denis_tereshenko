# Экзамен Дениса Терещенко

Локальная экзаменационная система для Python и Java в стиле старого хакерского терминала. Работает в Docker Desktop и открывается на компьютерах одной локальной сети.

![Главный экран](static/assets/denis-skull.png)

## Возможности

- Приветственный экран: матричный фон, череп в очках и многоступенчатое подключение к экзаменационному узлу.
- Вход студента по группе, имени и фамилии из разрешённого списка.
- Вход преподавателя и панель с попытками, баллами, решениями и результатами.
- Выбор одного языка до начала экзамена: Python 3.12 или Java 21.
- Пять задач на 30 баллов: `5 + 5 + 5 + 5 + 10`.
- Общий таймер на 90 минут и сохранение решений.
- Офлайн-редактор кода с подсветкой синтаксиса, автодополнением и Tab-отступами.
- Запуск собственного кода на введённых данных с отображением настоящего вывода или ошибки.
- Проверка решений на экзаменационных тестах.
- Изолированное выполнение кода: без сети, с read-only файловой системой, лимитом памяти 128 МБ, лимитом процессов и времени.

## Быстрый запуск

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) и дождитесь статуса `Engine running`.
2. Откройте Терминал и перейдите в папку проекта:

```bash
cd /Users/tolikbeleckij/Documents/Codex/2026-10-20/lfd
```

3. Создайте локальный файл настроек и запустите проект:

```bash
cp .env.example .env
docker compose up --build -d
```

4. Откройте в браузере: [http://localhost:8000](http://localhost:8000).

Первый запуск скачивает образы Python и Java. После этого сам экзамен и исполнители работают локально.

### Управление контейнером

```bash
# Запустить после первого запуска
docker compose up -d

# Посмотреть журнал работы
docker compose logs -f exam

# Остановить сайт
docker compose down
```

Для доступа из локальной сети узнайте IP компьютера на macOS:

```bash
ipconfig getifaddr en0
```

Затем на другом устройстве откройте `http://IP-АДРЕС:8000`.

## Учётные данные и студенты

Тестовые учётные данные:

- преподаватель: `admin` / `admin`;
- студент: группа `ТЕСТ-01`, имя `Иван`, фамилия `Тестов`.

Разрешённые студенты хранятся в `students.json`. Для каждого студента нужны точные значения:

```json
{
  "group": "ТЕСТ-01",
  "first_name": "Иван",
  "last_name": "Тестов"
}
```

## Работа в редакторе

- `Tab` — отступ из четырёх пробелов;
- `Ctrl/Cmd + S` — сохранить текущий код;
- `Ctrl/Cmd + Enter` — выполнить код на собственных входных данных;
- `Alt + 1` … `Alt + 5` — переход между задачами.

Кнопка **«Выполнить код»** показывает фактический вывод программы. Кнопка **«Запустить тесты»** отдельно проверяет решение и начисляет баллы.

## Передача преподавателю одним файлом

Готовый архив находится в `outputs/denis-tereshchenko-exam-bundle.tar`. В нём уже есть сайт и образы исполнителей Python и Java. Исходники проекта передавать не нужно.

На компьютере преподавателя, где установлен Docker Desktop:

```bash
docker load -i denis-tereshchenko-exam-bundle.tar
docker volume create denis-exam-data
docker volume create denis-exam-submissions
docker run -d --name denis-exam -p 8000:8000 \
  -v denis-exam-data:/app/data \
  -v denis-exam-submissions:/app/submissions \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -e EXECUTOR_VOLUME=denis-exam-submissions \
  -e ADMIN_LOGIN=admin \
  -e ADMIN_PASSWORD=admin \
  -e SECRET_KEY=change-this-secret \
  lfd-exam:latest
```

После запуска сайт доступен на `http://localhost:8000`. Данные попыток сохраняются в Docker volume `denis-exam-data` и не пропадут при перезапуске контейнера.

## Безопасность

Проект предназначен для доверенной локальной сети, а не для публикации в интернете. Перед реальным экзаменом обязательно измените `ADMIN_PASSWORD` и `SECRET_KEY` в `.env` или в параметрах `docker run`.

Хотя код студентов запускается в ограниченных временных контейнерах, основной сервис использует Docker Desktop для их создания. Поэтому не предоставляйте доступ к сайту посторонним пользователям через публичный интернет.
